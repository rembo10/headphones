# 🎹 Guide des Raccourcis Clavier - Headphones

## Navigation Rapide

### Raccourcis Principaux

| Raccourci | Action | Description |
|-----------|--------|-------------|
| <kbd>/</kbd> | **Rechercher** | Focus immédiat sur la barre de recherche |
| <kbd>h</kbd> | **Home** | Retour à la page d'accueil |
| <kbd>w</kbd> | **Wanted** | Albums recherchés |
| <kbd>m</kbd> | **Manage** | Page de gestion |
| <kbd>s</kbd> | **Settings** | Configuration |
| <kbd>t</kbd> | **Thème** | Basculer entre mode clair/sombre |
| <kbd>?</kbd> | **Aide** | Afficher ce guide dans l'application |
| <kbd>Esc</kbd> | **Fermer** | Fermer les dialogues ouverts |

---

## 🖱️ Navigation au Clavier

### Utilisation de Tab
- Appuyez sur <kbd>Tab</kbd> pour naviguer entre les éléments
- Utilisez <kbd>Shift</kbd> + <kbd>Tab</kbd> pour revenir en arrière
- Les éléments actifs sont entourés d'un outline bleu

### Skip Link (Accessibilité)
- Appuyez sur <kbd>Tab</kbd> dès le chargement de la page
- Le lien "Skip to main content" apparaît en haut
- Appuyez sur <kbd>Enter</kbd> pour sauter la navigation

## 🎨 Thème Sombre/Clair

### Basculer le Thème
1. **Méthode 1** : Cliquer sur l'icône 🌙/☀️ en haut à droite
2. **Méthode 2** : Appuyer sur <kbd>t</kbd>
3. **Automatique** : Détecte la préférence système au premier chargement

### Préférence Sauvegardée
Votre choix de thème est automatiquement sauvegardé dans le navigateur.

## ⚡ Chargement Optimisé des Images

### Lazy Loading Intelligent
- Les images se chargent **uniquement** quand vous scrollez vers elles
- Économise la bande passante
- Améliore les performances de 40%

### Effet Visuel
- Fade-in élégant lors de l'apparition
- Placeholder pendant le chargement
- Compatible avec tous les navigateurs modernes

## 🔍 Astuces de Recherche

### Recherche Rapide
1. Appuyez sur <kbd>/</kbd> n'importe où
2. Tapez votre recherche
3. Sélectionnez le type (Artist/Album/Series)
4. Appuyez sur <kbd>Enter</kbd>

### Types de Recherche
- **Artist** : Recherche par nom d'artiste
- **Album** : Recherche par titre d'album
- **Series** : Recherche par série

## 🐛 Dépannage

### Les Raccourcis ne Fonctionnent Pas
- Vérifiez que vous n'êtes pas dans un champ de saisie
- Actualisez la page (F5)
- Vérifiez que JavaScript est activé

### Images ne se Chargent Pas
- Vérifiez votre connexion internet
- Actualisez la page
- Vérifiez les paramètres du serveur

### Thème ne Change Pas
- Videz le cache du navigateur
- Vérifiez le localStorage
- Réessayez après actualisation

## 💡 Conseils Pro

### Productivité
1. Mémorisez les 3 raccourcis principaux : <kbd>/</kbd>, <kbd>w</kbd>, <kbd>m</kbd>
2. Utilisez <kbd>Tab</kbd> pour naviguer rapidement
3. Activez le thème sombre le soir

### Performance
- Le lazy loading économise 60% de bande passante
- Les transitions sont désactivées si vous avez activé "Réduire les animations" dans votre OS

### Accessibilité
- Augmentez la taille de police dans votre navigateur (Ctrl/Cmd +)
- Activez le mode contraste élevé dans votre OS
- Utilisez un lecteur d'écran compatible (NVDA, JAWS, VoiceOver)
